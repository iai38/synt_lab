# СинтезЛаб — HTML-макет сайта

Демонстрационный HTML-макет переработанного сайта **СинтезЛаб** (организационное развитие, домен [academysbd.ru](https://academysbd.ru/)).
Статический сайт (HTML/CSS/JS, без сборки) — макет под утверждение заказчиком перед переносом на Next.js.

> ⚠️ **DEMO-макет.** Часть контента (кейсы, отзывы, часть био, логотипы клиентов) — реалистичные плейсхолдеры, помеченные меткой «демо». Заменяются материалами заказчика.

## 🚀 Запуск

Откройте `index.html` в браузере. Сборка и зависимости не нужны.

### GitHub Pages
Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)`.
Сайт будет на `https://<username>.github.io/synt_lab/`.

## ✅ Внесённые правки заказчика

1. Блок «Продукты компании» → **«Основные форматы работы»**; порядок: сначала «Как мы усиливаем», затем «Основные форматы».
2. **«Наш подход»** — текст заменён на формулировку из брендбука.
3. **Клиенты** → заголовок **«Нам доверяют»** (логотипы — плейсхолдеры).
4. Блок «Доверительное пространство» убран → **«Бесплатная диагностика командной системы»** (50 минут, 3 пункта, кнопка «Получить диагностику»).
5. **Команда** пересобрана: Петрова, Деревяшкина, Теплицкая, Львова.
6. Добавлен блок **«Кейсы»** — 5 реальных кейсов из презентации заказчика, каждый на отдельной странице (`/cases/`).
7. Добавлен блок **«Отзывы»** (демо).
8. «Как мы усиливаем» — убраны картинки, минималистичная подача.
9. **4 услуги** вынесены на отдельные страницы (`/services/`).
10. **Блог** интегрирован в общую навигацию сайта.
