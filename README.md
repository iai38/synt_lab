# Блог СинтезЛаб — демонстрационный раздел

Демо-версия раздела **«Блог»** для сайта консалтинговой компании [СинтезЛаб](https://academysbd.ru/).
Статический сайт (HTML/CSS/JS, без сборки) — готов к публикации на GitHub Pages.

## 🎯 Что это

Раздел блога спроектирован как демонстрация для потенциального заказчика. Сейчас на действующем
сайте блог неактивен — этот прототип показывает, как он может выглядеть и работать: с продуманной
SEO-структурой, рубриками, хлебными крошками и фирменной цветовой схемой.

## 🚀 Запуск

Просто откройте `index.html` в браузере. Сборка и зависимости не нужны.

### Публикация на GitHub Pages
1. Settings → Pages → Source: `Deploy from a branch`
2. Branch: `main`, папка `/ (root)` → Save
3. Через минуту сайт будет доступен по адресу `https://<username>.github.io/synt_lab/`

## 🔍 SEO-решения

Раздел изначально спроектирован под поисковую оптимизацию:

- **Семантическая разметка** — `article`, `nav`, `time`, корректная иерархия заголовков `h1–h3`
- **Хлебные крошки** на каждой странице + микроразметка `BreadcrumbList` (JSON-LD)
- **Schema.org** — `Blog` на листинге, `BlogPosting` на каждой статье (автор, дата, рубрика)
- **Мета-теги** — уникальные `title` и `description`, `keywords`, `canonical`, `robots`
- **Open Graph** + Twitter Card для красивых превью при репостах
- **Рубрикация** — 5 рубрик: Команды, Лидерство, Стратегия, Медиация, Кейсы
- **sitemap.xml** и **robots.txt**
- **ЧПУ-структура** ссылок (человекопонятные URL)
- Адаптивная вёрстка (десктоп / планшет / мобильный)
